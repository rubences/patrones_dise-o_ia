# Editorial route decision

## Research monograph (EN)

Priority order for first approach:

1. Springer Nature — Computer Science book programme.
2. CRC Press / Taylor & Francis.
3. Wiley-IEEE Press.

Rationale: all three routes publicly support research/professional books in computer science or related engineering fields. The order is a working acquisition strategy, not a quality ranking. Re-route if an editor indicates a better imprint/series fit.

## Teaching manual (ES)

Priority order for first approach:

1. RA-MA.
2. Ediciones Paraninfo.

Rationale: RA-MA publishes a precise public manuscript package that already matches the prepared dossier and explicitly targets technical/professional works within undergraduate/postgraduate programmes. Paraninfo is a strong fit for University/Computer Science but its public initial submission package is less prescriptive, so the first step there should be confirmation with the editor.

## Independence rule

The two routes may progress in parallel because the works are editorially independent, but any exclusivity language received from either publisher must pass `CONTRACT_RIGHTS_GATE.md` before it is accepted.
