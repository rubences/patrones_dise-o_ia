# Common publication controls

This directory contains controls shared by both independent editorial works without turning them into translations of each other.

- `publisher-submission-requirements.json` — machine-readable registry of publicly verified publisher routes and requirements.
- `PUBLISHER_SUBMISSION_MATRIX.md` — operational human-readable routing matrix.
- `CONTRACT_RIGHTS_GATE.md` — contract, rights, reuse and derivative-work gate.
- `SUBMISSION_CHANGELOG.md` — dated verification history.
- `ANECA_STRATEGY_NOTES.md` — evaluation-strategy notes; re-check official criteria before any formal accreditation use.
- `EDITORIAL_SEPARATION_POLICY.md` — boundary between shared technical substrate and distinct editorial works.

The publisher registry is intentionally conservative: when a publisher does not publicly state an exact initial requirement, the value is recorded as `confirm-with-editor-before-submission` rather than guessed.
