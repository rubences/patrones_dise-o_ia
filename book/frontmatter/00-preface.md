# Prefacio

Los sistemas de inteligencia artificial modernos ya no son una única llamada a un modelo. Combinan recuperación, herramientas, memoria, orquestación, observabilidad, evaluación, seguridad y decisiones humanas. El objetivo de este libro es dar nombre y estructura a soluciones recurrentes para que puedan discutirse, compararse, probarse y componerse.

Esta obra nace junto a una biblioteca ejecutable: cada patrón editorial apunta a una implementación TypeScript. El código no pretende convertir una demostración pedagógica en una garantía de producción; por eso las fichas distinguen explícitamente intención, comportamiento implementado, limitaciones, evidencia y endurecimiento necesario.

El catálogo se genera desde una única fuente canónica compartida con la web. El manuscrito resultante es, por diseño, un artefacto derivado y reproducible.
