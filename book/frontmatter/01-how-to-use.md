# Cómo utilizar este libro

No es necesario leer los 102 patrones en orden. Las diez partes funcionan como mapas de decisión: fundamentos, flujos agénticos, conocimiento y contexto, razonamiento, multiagente, seguridad, fiabilidad, producción, evaluación y experiencia humana.

Cada patrón responde a cuatro preguntas mínimas: **qué problema resuelve**, **qué hace realmente la implementación del repositorio**, **qué cambia al llevarlo a producción** y **con qué otros patrones se relaciona**. Las etiquetas de madurez y evidencia no son rankings de calidad; sirven para separar soluciones asentadas, demos parciales y áreas donde todavía falta validación.

Una arquitectura real suele necesitar una composición. Por ejemplo, un agente con herramientas puede combinar Router, Planning, Tool Use, Access Control, Tool Call Validation, Human-in-the-Loop, Observability y Regression Testing. El valor está en las fronteras entre patrones y en los invariantes que se mantienen al componerlos.
